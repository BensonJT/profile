# Public document privacy rules

Applies to everything published at bensonjt.github.io/profile and to the résumé
PDF linked from it.

## Never on a public page or the public PDF

- Street address
- Personal email address
- Phone number

Rationale: these documents are scraped, and they persist in third-party ATS
databases indefinitely. An exposed email produces spam; an exposed home address
and phone produce worse.

## What public documents carry instead

| Field | Public value |
| --- | --- |
| Location | **Northern Virginia** — enough to signal commute radius and market, not enough to locate a house |
| Contact | LinkedIn profile link only |
| Code | GitHub profile link |

## The private version

A separate résumé carrying full contact details is provided **directly to a real
recruiter or hiring manager on request**, after contact is established. That file
is never committed to this repo and never linked from the site.

Keep it out of the repo entirely. `Jeffrey_Benson_Resume.pdf` in this directory
is the public version and must satisfy the rules above.
