Privacy

Privacy policy.

This site collects nothing about you. My personal tools touch only my own data.

This website

This site is a set of static pages hosted on GitHub Pages. It uses no cookies, no analytics, no tracking scripts and no forms, and I collect no personal information from visitors. GitHub, as the host, may log technical data such as IP addresses under the GitHub Privacy Statement.

My personal tools that use Google APIs

I run a few small tools for my own use, such as a file-backup client for my own Google Drive and a spreadsheet utility. They are not offered to the public. Each one signs in only to my own Google account, with my consent, and uses Google user data only to do the task I ask of it: copying, checking and reading my own files.

  • Data moves only between my own computers and my own Google account.
  • It is never sold, shared with anyone else, or used for advertising.
  • It is never used to train AI or machine-learning models.
  • Sign-in tokens are stored only on my own computers, never in a code repository.

These tools’ use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Access can be removed at any time at myaccount.google.com/permissions.
