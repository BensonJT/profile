Field workforce capacity

Workforce planning · Verizon network operations · 1,000 technicians

2023 – 2025

Situation
A 1,000-technician field operation paid overtime while skills sat idle elsewhere in the same operation. My manager had worked the problem for 9 months.
Obstacle
The work-area map underneath dispatch had no governance. It was incomplete and overlapping: one ZIP code could sit in 6 areas.
Action
Rebuilt the map with the field supervisors, placing every ZIP code in exactly one contiguous area. Then built a Force-to-Load capacity model in Python and SQL matching skill supply to demand by geography and shift.
Result
Auto-dispatch rose from 30–40% to 70–80% on the map work alone. The model surfaced $18–22M of hidden capacity and supported a 50 FTE business case that was approved.
